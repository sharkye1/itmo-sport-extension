# ITMO Sport: Доступные места

Расширение для Chrome, которое скрывает прошедшие пары и занятия с 0 свободных мест на странице записи на физкультуру в ИТМО ([my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign)).

## В чём проблема сайта
На my.itmo.ru галочка «Доступные для записи» работает странно:
1. Если у секции есть хотя бы одно свободное занятие где-то в течение семестра, сайт покажет её на текущей неделе — даже если на выбранный день мест `0 / 30`.
2. В расписании продолжают висеть пары за прошедшие дни недели и прошедшие слоты текущего дня, на которые записаться уже физически нельзя.

В итоге приходится кликать по каждой карточке наугад, чтобы найти доступную пару.

## Что делает расширение
- **Скрывает пары с 0 мест и прошедшие занятия**: остаются только актуальные пары, куда реально можно записаться прямо сейчас.
- **Показывает места на карточках**: сразу видно остаток мест (например, `5 / 30 мест`), кликать на каждую карточку больше не нужно.
- **Добавляет кнопку на страницу**: прямо рядом со штатной галочкой «Доступные для записи» появляется тумблер «Только с местами (> 0)». Если понадобится посмотреть всю сетку, фильтр выключается в один клик.
- **Обновляется само**: расписание пересчитывается при смене недели, фильтров или когда сайт подтягивает свежие лимиты мест.

## Как установить в Chrome (за 1 минуту)

1. Скачайте репозиторий:
   - Нажмите зеленую кнопку **Code** ➔ **Download ZIP** и распакуйте архив.
   - Либо через терминал: `git clone https://github.com/<username>/itmo-sport-extension.git`
2. В Chrome перейдите по адресу:
   ```
   chrome://extensions/
   ```
3. В правом верхнем углу включите **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку с расширением.
6. Откройте [my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign) (или обновите страницу через `F5`, если она уже открыта).
