# ITMO Sport: Доступные места

Расширение для Chrome, которое наводит порядок на странице записи на физкультуру в ИТМО ([my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign)).

## В чём проблема сайта
На my.itmo.ru встроенные фильтры неудобные:
1. Галочка «Доступные для записи» проверяет места не на выбранный день, а за весь семестр. Из-за этого показываются занятия с `0 / 30` мест на сегодня.
2. В сетке висят прошедшие дни недели и утренние пары, на которые запись уже закрыта.
3. Чтобы понять, пересекается ли спорт с твоими парами по расписанию, нужно вручную искать красные точки на карточках.

## Что делает расширение
- **Скрывает пары с 0 мест и прошедшие занятия**: оставляет только актуальные слоты, куда реально можно записаться прямо сейчас.
- **Фильтрует пересечения с парами**: тумблер «Без пересечений» убирает все секции, которые накладываются на твоё учебное расписание (пары в ИСУ).
- **Показывает места прямо на карточках**: сразу видно количество свободных мест (например, `5 / 30 мест`), не нужно кликать на всё подряд.
- **Встраивает кнопки прямо на страницу**: рядом со штатным переключателем появляются удобные тумблеры «Только с местами (> 0)» и «Без пересечений».
- **Обновляется само**: сетка автоматически пересчитывается при смене недели, фильтров или при обновлении лимитов с сервера.

## Как установить в Chrome (за 1 минуту)

1. Скачайте репозиторий:
   - Нажмите зеленую кнопку **Code** ➔ **Download ZIP** и распакуйте архив.
   - Либо через терминал: `git clone https://github.com/sharkye1/itmo-sport-extension.git`
2. В Chrome перейдите по адресу:
   ```
   chrome://extensions/
   ```
3. В правом верхнем углу включите **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку с расширением.
6. Откройте [my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign) (или обновите страницу через `F5`, если она уже открыта).
