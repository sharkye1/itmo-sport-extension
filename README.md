# ITMO Sport: Доступные места

Расширение для Chrome, которое наводит порядок на странице записи на физкультуру в ИТМО ([my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign)).

## В чём проблема сайта
1. **Показываются занятия с 0 мест**: встроенная галочка «Доступные для записи» проверяет наличие мест не на текущий день, а за весь семестр. Из-за этого отображаются занятия, где на сегодня мест `0 / 30`.
2. **Висят прошедшие пары**: в расписании остаются предыдущие дни недели и утренние слоты, куда запись уже закрыта.
3. **Нельзя выбрать несколько корпусов**: на сайте можно выбрать только один корпус за раз. Если у тебя свободный день и ты готов поехать и на Ломоносова, и на Вяземский (или в бассейн на стороннем объекте), приходится переключать выпадающий список туда-обратно.
4. **Неудобно искать пересечения с парами**: нужно вручную выискивать мелкие красные точки на каждой карточке.

## Что делает расширение
- **Выбор нескольких корпусов одновременно**: прямо над расписанием появляются кнопки-чипы (Ломоносова, Вяземский, Кронверкский, Сторонние объекты и т.д.). Можно выбрать 2, 3 или все корпуса сразу — занятия объединятся в одну общую сетку с аккуратными метками `📍 Ломоносова` / `📍 Вяземский`.
- **Скрывает пары с 0 мест и прошедшие занятия**: тумблер «Только с местами (> 0)» оставляет только актуальные пары со свободными местами.
- **Фильтрует пересечения с парами**: тумблер «Без пересечений» убирает секции, которые накладываются на твоё учебное расписание (пары в ИСУ).
- **Показывает количество мест на карточках**: сразу видно остаток (например, `5 / 30 мест`), не нужно открывать каждую карточку наугад.
- **Обновляется само**: сетка автоматически пересчитывается при смене недели, фильтров или при обновлении лимитов с сервера.

## Как установить в Chrome (за 1 минуту)

1. Скачайте репозиторий:
   - Нажмите зеленую кнопку **Code** ➔ **Download ZIP** и распакуйте архив.
   - Либо через терминал: `git clone https://github.com/sharkye1/itmo-sport-extension.git`
2. В Chrome перейдите по адресу:
   ```
   chrome://extensions/
   ```
3. В правом верхнем углу включите **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку с расширением.
6. Откройте [my.itmo.ru/sport/sign](https://my.itmo.ru/sport/sign) (или обновите страницу через `F5`, если она уже открыта).
